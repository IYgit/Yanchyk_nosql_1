MongoDB Atlas

MongoDB Atlas — це хмарна платформа для хостингу MongoDB, яку надає сама компанія MongoDB. Замість того, щоб встановлювати та налаштовувати базу даних локально, ви розгортаєте керований кластер у хмарі (AWS, GCP або Azure) у кілька кліків. Atlas бере на себе резервне копіювання, моніторинг, оновлення та налаштування Replica Set — вам залишається лише підключитися та працювати з даними.

Для цього завдання достатньо безкоштовного тиру M0 Shared.


Порядок налаштування:

Зареєструйтеся на mongodb.com/atlas.
Створіть кластер — виберіть провайдера AWS та регіон, найближчий до вас.
У розділі Database Access створіть користувача з паролем.
У розділі Network Access додайте свій IP (або 0.0.0.0/0 для розробки).
Натисніть Connect → Drivers, скопіюйте рядок підключення вигляду mongodb+srv://... — він знадобиться у скриптах.


Atlas M0 вже працює як Replica Set із трьох нод. У цьому завданні вам не потрібно окремо налаштовувати Replica Set — достатньо створити кластер Atlas і використати його для роботи з даними.

1.1. Завантаження сирих даних

Виконайте скрипт.

# scripts/01_load_data.py
import os
import ast
import pandas as pd
from pymongo import MongoClient
from tqdm import tqdm
from dotenv import load_dotenv


load_dotenv()


MONGO_URI = os.environ["MONGO_URI"]
DB_NAME = "spotify"
CSV_PATH = "dataset.csv"     # шлях до завантаженого файлу з Kaggle
BATCH_SIZE = 1000


client = MongoClient(MONGO_URI)
db = client[DB_NAME]


# Видаляємо колекцію якщо існує — для ідемпотентного повторного запуску
db["tracks_raw"].drop()


df = pd.read_csv(CSV_PATH)
print(f"Завантажуємо{len(df)} треків...")


# Приводимо типи
df["explicit"] = df["explicit"].astype(bool)


# Цілі числа
int_cols = ["popularity", "duration_ms", "key", "mode", "time_signature"]
for col in int_cols:
    df[col] = df[col].astype(int)


# Числа з плаваючою точкою
float_cols = [
    "danceability", "energy", "loudness", "speechiness",
    "acousticness", "instrumentalness", "liveness",
    "valence", "tempo"
]
for col in float_cols:
    df[col] = df[col].astype(float)


# Прибираємо записи, в яких немає виконавця або назви треку
query = df["artists"].isna() | df["track_name"].isna()
records = df[~query].to_dict("records")


# Завантажуємо батчами — вставка 114k документів однією операцією може впасти по пам'яті
for i in tqdm(range(0, len(records), BATCH_SIZE)):
    db["tracks_raw"].insert_many(records[i : i + BATCH_SIZE])


print(f"Завантажено документів:{db['tracks_raw'].count_documents({})}")
print(f"Приклад документа:")
print(db["tracks_raw"].find_one())



1.2. Трансформація схеми через Aggregation Pipeline

Сирі дані мають плоску структуру у форматі CSV. Треба трансформувати їх у документоорієнтовану схему, а саме винести аудіохарактеристики в окремий вкладений об’єкт, розбити рядок із виконавцями на масив та додати обчислювані поля.



Виконайте підготовлений JS-скрипт для MongoDB

// scripts/02_transform.js
// Запуск: mongosh "ВАШ_URI" --file scripts/02_transform.js


db = db.getSiblingDB("spotify");
db["tracks"].drop();


db["tracks_raw"].aggregate([
  // ======================================================
  // Стадія 1: Проєкція потрібних полів
  // ======================================================
  {
    $project: {
      _id: 0,
      track_id: 1,
      track_name: 1,
      album_name: 1,
      explicit: 1,
      popularity: 1,
      duration_ms: 1,
      track_genre: 1,
      danceability: 1,
      energy: 1,
      loudness: 1,
      speechiness: 1,
      acousticness: 1,
      instrumentalness: 1,
      liveness: 1,
      valence: 1,
      tempo: 1,
      key: 1,
      mode: 1,
      time_signature: 1,
      artists_raw: "$artists" // рядок з артистами через ;
    }
  },


  // ======================================================
  // Стадія 2: Розбиваємо artists на масив по ;
  // "Drake; Future" → ["Drake", "Future"]
  // ======================================================
  {
    $addFields: {
      artists: {
        $map: {
          input: { $split: ["$artists_raw", ";"] },
          as: "artist",
          in: { $trim: { input: "$$artist" } } // прибираємо пробіли навколо
        }
      }
    }
  },


  // ======================================================
  // Стадія 3: Формуємо audio_features та обчислюємо нові поля
  // ======================================================
  {
    $addFields: {
      audio_features: {
        danceability:     "$danceability",
        energy:           "$energy",
        loudness:         "$loudness",
        speechiness:      "$speechiness",
        acousticness:     "$acousticness",
        instrumentalness: "$instrumentalness",
        liveness:         "$liveness",
        valence:          "$valence",
        tempo:            "$tempo",
        key:              "$key",
        mode:             "$mode",
        time_signature:   "$time_signature"
      },
      duration_sec: { $round: [{ $divide: ["$duration_ms", 1000] }, 1] },
      popularity_tier: {
        $switch: {
          branches: [
            { case: { $gte: ["$popularity", 70] }, then: "high" },
            { case: { $gte: ["$popularity", 40] }, then: "medium" }
          ],
          default: "low"
        }
      }
    }
  },


  // ======================================================
  // Стадія 4: Прибираємо старі поля
  // ======================================================
  {
    $unset: [
      "artists_raw", "danceability", "energy", "loudness",
      "speechiness", "acousticness", "instrumentalness",
      "liveness", "valence", "tempo", "key", "mode", "time_signature"
    ]
  },


  // ======================================================
  // Стадія 5: Виводимо результат у нову колекцію tracks
  // ======================================================
  { $out: "tracks" }


]);


print("Трансформацію завершено.");
print("Документів у tracks: " + db["tracks"].countDocuments());
print("Приклад документа:");
printjson(db["tracks"].findOne());



Цей скрипт виконує наступні кроки:



Створення нової колекції tracksСкрипт використовує базу даних spotify.
Перед трансформацією скрипт видаляє стару колекцію tracks, якщо вона існує.
Проєкція полівСкрипт залишає лише потрібні для аналізу поля: track_id, track_name, album_name, explicit, popularity, duration_ms, track_genre та рядок із виконавцями (artists_raw).
Перетворення виконавцівСкрипт розбиває рядок із виконавцями за роздільником ; та прибирає пробіли навколо кожного імені.
Результат зберігається в полі artists як масив.
Формування аудіохарактеристик та обчислюваних полівСкрипт створює вкладений об’єкт audio_features, який включає всі аудіохарактеристики: danceability, energy, loudness, speechiness, acousticness, instrumentalness, liveness, valence, tempo, key, mode, time_signature.
Скрипт додає поле duration_sec — тривалість треку в секундах, округлену до одного знака після коми.
Скрипт додає поле popularity_tier:
high — популярність ≥ 70;
medium — популярність ≥ 40 і < 70;
low — популярність < 40.
Очищення зайвих полівСкрипт видаляє вихідні аудіохарактеристики та поле artists_raw.
Збереження результатуСкрипт зберігає перетворені документи в колекції tracks.
Перевірка результатуСкрипт виводить кількість документів у колекції tracks.
Скрипт виводить один приклад документа для перевірки структури.
